NOAH DIGITAL STORES — BUSINESS DESK (FREE OFFLINE VERSION)
==========================================================

WHAT IS INCLUDED
- Customer request / NOAH REQUEST tracker with unique request numbers
- Customer, product, budget, area, fee, fee payment status and progress tracking
- Supplier directory
- Basic income/expense/commission records
- Ready-to-copy WhatsApp replies
- Seven marketing captions
- CSV export and JSON backup/restore
- Editable business name, slogan, base service fee, area, optional WhatsApp and social links

HOW TO START
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Start on the Dashboard, then add a request.
4. Add trusted suppliers under Wauzaji.
5. Use Matangazo and Majibu ya WhatsApp to copy prepared text.
6. Download a JSON backup regularly from Mipangilio na Backup.

IMPORTANT LIMITS
- This is a local/offline business dashboard. It does not require a subscription or server.
- Data is saved in the browser storage on the device where it is opened. It does not sync to another phone/computer.
- Use the same browser/profile to continue using the saved data. Clearing browser data can erase it.
- Download a JSON backup regularly and keep it in a safe place.
- It does NOT automatically receive WhatsApp messages, send automated WhatsApp replies, connect to WhatsApp Business API, search suppliers online, or run an AI model offline. Those capabilities require external services/API integrations and may have costs.
- WhatsApp buttons open a wa.me chat link for a customer whose phone number you have entered; they do not send without your action.
- The TZS 5,000 NOAH REQUEST fee is from the previous business plan and is editable in Settings. Clearly confirm the fee with each customer before starting.
- No verified official WhatsApp number, email, or website was found in the available business details, so these are left blank in Settings instead of inventing them.
